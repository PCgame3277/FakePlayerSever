# FakePlayerSever
一个我的世界基岩版（1.26.30+）的假人mod
FakePlayer mod for Minecraft Bedrock Edtion(1.26.30+)

我发现基岩版1.26之后基本没有适配的假人mod，手搓了一个最基础的，有假人，假人无法互动。你得用spawn_robot的生成蛋才能生成它。
I found that after Bedrock version 1.26, there are basically no compatible FakePlayer mods, so I hand-made a very basic one. It has a FakePlayer, but the FakePlayer can't interact. You have to use the "spawn_robot" spawn egg to create it.
